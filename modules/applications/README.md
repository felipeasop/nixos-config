# applications

Software que uma pessoa escolhe e usa. Um aspect por app, agrupado por
categoria; o host ou o usuário decide quais incluir.

- Bundles: `desktop-apps.nix`, `development/dev.nix`, `gaming/gaming-stack.nix`.
- `peripherals/`: software ligado a um periférico específico.
- `utilities/admin-tools.nix` e `utilities/unrar.nix`: no baseline de host.
